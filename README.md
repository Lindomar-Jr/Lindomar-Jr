## Sobre mim

Tenho 24 anos, moro no interior do RJ, em Nova friburgo, sou estudante de análise e desenvolvimento de sistemas, focado em desenvolvimento web full-stack.

Minha forma de estudar é baseada na prática: além dos cursos, gosto de desenvolver exercícios, desafios e projetos que consolidem cada novo conhecimento adquirido.
Gosto de compreender os fundamentos de cada tecnologia e entender por que cada solução funciona da forma como foi projetada. Para mim, é importante construir aplicações com clareza, organização e propósito, permitindo que qualquer pessoa consiga entender facilmente sua estrutura.

Atualmente estou construindo meu portfólio público no GitHub, documentando minha evolução desde os primeiros estudos em HTML até projetos full-stack utilizando JavaScript, banco de dados e tecnologias do ecossistema web.
